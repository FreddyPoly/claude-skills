Astuces de test

Astuces

  • Ajoutez + à une adresse e-mail (prenom+test1@domaine.com, prenom+test2@domaine.com...) pour accéder à plusieurs comptes avec une seule boîte mail.
  • Utilisez plusieurs navigateurs ou des fenêtres de navigation privée pour être connecté sur plusieurs comptes en même temps.

Légende des statuts

    Le statut d'un cas se calcule automatiquement à partir de ses étapes : vous ne le modifiez pas, vous renseignez seulement le résultat de chaque étape.

    En cas d'échec

    • Ajoutez une capture d'écran dans la colonne « Capture d'écran si échec » pour montrer où et quoi échoue, ajoutez au besoin une note sur l'étape.

    Données

    • Pas de données patient ou personnelles réelles, ni de mots de passe ou tokens dans les captures, notes et bugs : utilisez les comptes de test.

    Chargement du scénario… Les cas de test apparaissent dès que la base partagée répond.
